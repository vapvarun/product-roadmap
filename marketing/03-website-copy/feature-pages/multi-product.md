## OVERVIEW SECTION

### Content
What happens when you have more than one product? Or you're an agency with multiple clients? Or your enterprise has different departments?

You need separate roadmaps. Each product deserves its own space for items, votes, and feedback. But managing multiple WordPress installations? That's a nightmare.

Product Roadmap Pro's multi-product support solves this elegantly. Create as many products as you need, each with its own roadmap, and manage everything from a single dashboard.

## HOW IT WORKS SECTION

### Section Header
**Multi-Product Made Simple**

### 1. Create Products
Go to Roadmap → Products and create entries for each product:
- Mobile App
- Web Platform
- API/SDK
- Or your client names

### 2. Assign Items
When creating or editing roadmap items, select which product they belong to. One item can belong to multiple products if needed.

### 3. Display Separately
Use shortcodes to show specific product roadmaps:
```
[roadmap product="mobile-app"]
[roadmap product="web-platform"]
```

### 4. Analyze Individually
Filter analytics by product to see engagement for each roadmap separately.

## SETUP GUIDE SECTION

### Section Header
**Getting Started**

### Step 1: Create Your Products
1. Go to Roadmap → Products
2. Add New Product
3. Enter name (e.g., "Mobile App")
4. Slug auto-generates (or customize)
5. Add description (optional)
6. Click Add

Repeat for each product you need.

### Step 2: Assign Existing Items
If you have existing items:
1. Edit each item
2. In sidebar, check appropriate product(s)
3. Update the item

Or use bulk edit for many items.

### Step 3: Create Product Pages
For each product roadmap:
1. Create a new WordPress page
2. Name it clearly (e.g., "Mobile App Roadmap")
3. Add shortcode: `[roadmap product="mobile-app"]`
4. Publish

### Step 4: Link to Roadmaps
Add navigation for users to find the right roadmap:
- Add to main menu
- Create a "Roadmaps" index page
- Link from product pages

## BEST PRACTICES SECTION

### Section Header
**Multi-Product Tips**

### Naming Conventions
Use clear, consistent names:
- Product names customers recognize
- Match your marketing terminology
- Keep slugs simple for shortcodes

### Consistent Statuses
Use the same statuses across products:
- Planned, In Progress, Complete
- Same colors for recognition
- Easier for users who follow multiple products

### Product Index Page
Create a landing page listing all product roadmaps:
- Brief description of each product
- Link to each roadmap
- Help users find the right one

### Cross-Product Items
For items affecting multiple products:
- Assign to all relevant products
- Appears on each roadmap
- One item, multiple visibility

### Default Product
If most items belong to one product:
- Set a default in your workflow
- New items auto-assign
- Reduces manual work

## FAQ SECTION

### Q: Is there a limit to products?
**A:** No hard limit. Default maximum is 10, configurable in Pro settings.

### Q: Can one item belong to multiple products?
**A:** Yes. Assign multiple products to any item. It appears on each product's roadmap.

### Q: Can I move items between products?
**A:** Yes. Edit the item and change the product assignment. It's just a taxonomy.

### Q: Do votes carry across products?
**A:** Votes belong to the item, which can appear on multiple product roadmaps. Vote once, visible everywhere the item appears.

### Q: Can I have product-specific settings?
**A:** Currently, settings are global. Per-product settings may come in future versions.

### Q: How do I show all products together?
**A:** Omit the product parameter: `[roadmap]` shows all items regardless of product.
