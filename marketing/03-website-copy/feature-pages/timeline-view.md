## PLANNING WITH TIMELINE

### Section Header
**Effective Timeline Planning**

### Setting Target Dates
For items to appear on timeline:
1. Edit the roadmap item
2. Set a target date in the Pro meta box
3. Save - item appears on timeline at that date

### Showing Duration
Items span based on:
- Target date (end)
- Start date (if set)
- Single date shows as point/short bar

### Managing Dependencies
Create dependencies between items:
1. Edit the parent item
2. Select dependent items in Pro meta box
3. Lines appear on timeline connecting them

### Progress Updates
Update progress for accurate visualization:
1. Edit item
2. Set progress percentage (0-100)
3. Timeline shows progress bar filling

## FAQ SECTION

### Q: Do all items appear on the timeline?
**A:** Only items with target dates appear. Items without dates show in board view but not timeline.

### Q: Can I drag items to reschedule?
**A:** Yes, if drag & drop is enabled in Pro settings. Drag an item to move its target date.

### Q: What determines item bar length?
**A:** If you set both start and target date, the bar spans that range. Single date shows as a short bar.

### Q: Can visitors see the timeline?
**A:** Yes. Use `[roadmap template="timeline"]` shortcode to display timeline publicly.

### Q: How do I print the timeline?
**A:** Use browser print. Consider PDF export or screenshot tools for best results.

### Q: Can I embed timeline in presentations?
**A:** Share the page URL, take a screenshot, or use browser present mode.
