5. You sort by votes to see priorities

**Speaker Notes:**


- `product` - Which product to show
- `template` - Display template
- `status` - Filter by status
- `show_voting` - Enable/disable voting
- `show_filters` - Show filter bar
- `orderby` - Sort order

**Visual:**

**Speaker Notes:**
The basic shortcode is all most people need. But there are many parameters available for customization without touching code.

## Slide Design Notes

### Using These Slides

1. **Standalone Presentations** - Use a section as its own deck
2. **Appending to Overview** - Add sections after the main overview
3. **Customer Conversations** - Pick relevant sections for specific audiences
4. **Training Materials** - Use for onboarding new users

### Per-Section Recommendations

| Section | Best For |
|---------|----------|
| Voting | All audiences - core feature |
| Suggestions | Product managers, community builders |
| Analytics | Executives, data-driven teams |
| Templates | Agencies, design-focused teams |
| Multi-Product | Agencies, SaaS with multiple offerings |
| Setup | New users, demos |

### Customization Tips

- Add your own screenshots from your setup
- Include customer testimonials if available
- Add pricing slide at end of each section if presenting to prospects
- Customize speaker notes for your delivery style
