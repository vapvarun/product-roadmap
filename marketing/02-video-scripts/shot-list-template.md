# Product Roadmap - Video Shot List & Recording Guide

## Overview

This document provides a comprehensive shot list for all marketing videos and guidance for recording high-quality product demonstrations.

---

## Recording Environment Setup

### WordPress Installation
- **Version:** Latest WordPress (6.4+)
- **Theme:** Clean modern theme (Twenty Twenty-Four or flavor theme)
- **Plugins:** Only Product Roadmap + Pro (no conflicting plugins)
- **User:** Create fresh admin account with professional display name
- **URL:** Use clean URL (demo.example.com or similar)

### Browser Setup
- **Browser:** Google Chrome (latest)
- **Extensions:** Disable all extensions
- **Bookmarks bar:** Hidden
- **Zoom level:** 100%
- **Window size:** 1920x1080 minimum
- **Dark/light mode:** Light mode recommended

### Demo Data
Run setup wizard with demo import to populate:
- 11 sample roadmap items
- Multiple statuses (Planned, In Progress, Complete, etc.)
- Various categories (Feature, Enhancement, Bug Fix)
- Some items with votes and comments

### Additional Pro Demo Data
For Pro features, manually add:
- Multiple products (3 minimum)
- Items with target dates (for timeline)
- Items with dependencies
- Items with assignees
- Items with progress percentages
- Voting history over past 30 days

## Recording Best Practices

### Mouse Movement
- Move cursor slowly and deliberately
- Pause briefly before clicking
- Avoid erratic movements
- Keep cursor near action areas

### Timing
- Wait for page loads to complete
- Pause after important actions
- Allow time for animations
- Count "1-2" before moving on

### Consistency
- Same zoom level throughout
- Same browser window size
- Same demo data across recordings
- Same WordPress admin color scheme

### Quality Checks
- No personal data visible
- No error messages (unless intentional)
- Clean URLs in address bar
- No notifications or popups

## Post-Production Notes

### Editing Requirements
- Add cursor highlights for clicks
- Zoom into important areas
- Add text annotations
- Include progress indicators for long recordings
- Add intro/outro slides

### Export Settings
- Resolution: 1920x1080 minimum
- Frame rate: 30fps (60fps for smooth animations)
- Format: MP4 with H.264 codec
- Audio: AAC if narration included

### Thumbnail Requirements
- 1280x720 minimum
- Clear text overlays
- Product screenshot visible
- Brand colors
- Play button indicator (optional)
