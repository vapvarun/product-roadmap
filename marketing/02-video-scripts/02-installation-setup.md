# Installation & Setup Tutorial Script

## Video Details
- **Title:** How to Set Up Product Roadmap for WordPress (Complete Guide)
- **Duration:** 5-6 minutes
- **Purpose:** Tutorial for new users
- **Tone:** Helpful, clear, step-by-step
- **Target:** New users who downloaded the plugin

---

## Script

### INTRO (0:00 - 0:20)

**VISUAL:** Product logo, then WordPress dashboard

**NARRATOR:**
> "Welcome! In this video, I'll show you how to set up Product Roadmap on your WordPress site in just a few minutes. By the end, you'll have a fully functional public roadmap with voting and suggestions. Let's get started."

**ON-SCREEN TEXT:** "Setup Product Roadmap in 5 Minutes"

---

### STEP 1: INSTALLATION (0:20 - 1:00)

**VISUAL:** WordPress dashboard → Plugins → Add New

**NARRATOR:**
> "First, let's install the plugin. Go to your WordPress dashboard, click Plugins, then Add New."

**ON-SCREEN TEXT:** "Step 1: Install the Plugin"

**VISUAL:** Search for "Product Roadmap"

> "Search for 'Product Roadmap' - look for the one by WBcom Designs."

**VISUAL:** Click Install, then Activate

> "Click Install Now, and once it's done, click Activate."

**VISUAL:** Plugin activated notification

> "Perfect. The plugin is now active. You'll notice a new 'Roadmap' menu item in your sidebar."

**ON-SCREEN TEXT:** "Plugin Activated ✓"

---

### STEP 2: SETUP WIZARD (1:00 - 2:30)

**VISUAL:** Click Roadmap menu, Setup Wizard appears

**NARRATOR:**
> "After activation, the setup wizard should appear automatically. If not, just click 'Roadmap' in your sidebar and you'll see the option to run the wizard."

**ON-SCREEN TEXT:** "Step 2: Run the Setup Wizard"

**VISUAL:** Wizard Step 1 - Welcome

> "Let's walk through each step. First, we have a welcome screen explaining what the wizard does. Click 'Let's Go' to continue."

**VISUAL:** Wizard Step 2 - Product Setup

> "Step two: Configure your product. Give it a name - this is what your roadmap will be called. You can use your company name, product name, or something like 'Feature Roadmap'. I'll call mine 'My Product'."

**ON-SCREEN TEXT:** "Name your roadmap"

**VISUAL:** Fill in product name, click Continue

**VISUAL:** Wizard Step 3 - Status Setup

> "Step three: Set up your statuses. These are the stages features move through - like 'Planned', 'In Progress', and 'Complete'. The defaults work great for most people. You can always customize these later."

**ON-SCREEN TEXT:** "Configure statuses"

**VISUAL:** Wizard Step 4 - Import Demo Content

> "Step four: Import demo content. This is optional but really helpful. It adds sample roadmap items so you can see exactly how everything looks. I recommend importing it, then deleting the demo items later."

**ON-SCREEN TEXT:** "Import demo content (recommended)"

**VISUAL:** Check import box, click Continue

**VISUAL:** Wizard Step 5 - Complete

> "Step five: We're done! The wizard creates a roadmap page for you automatically. Click 'View Your Roadmap' to see it in action."

**ON-SCREEN TEXT:** "Setup Complete ✓"

---

### STEP 3: VIEW YOUR ROADMAP (2:30 - 3:15)

**VISUAL:** Frontend roadmap page with demo content

**NARRATOR:**
> "Here's your new public roadmap! If you imported demo content, you'll see sample items in different status columns."

**ON-SCREEN TEXT:** "Step 3: View Your Roadmap"

**VISUAL:** Point out key elements

> "Let me show you what's here. At the top, you might see filter options. Each column represents a status - Planned, In Progress, Complete, and so on. Each card is a roadmap item with a title, category, and vote count."

**VISUAL:** Hover over vote button

> "See this vote button? Click it to vote for a feature. The count updates immediately."

**VISUAL:** Click on an item

> "Click any item to see its detail page with full description, comments, and voting."

---

### STEP 4: CUSTOMIZE SETTINGS (3:15 - 4:15)

**VISUAL:** WordPress Admin → Roadmap → Settings

**NARRATOR:**
> "Now let's customize your settings. Go to Roadmap, then Settings in your WordPress admin."

**ON-SCREEN TEXT:** "Step 4: Customize Settings"

**VISUAL:** General tab

> "In the General tab, you can change your product name, set labels, and configure how many items to show."

**VISUAL:** Scroll through settings

> "Scroll down and you'll find options for voting - whether to allow guest voting, who can submit suggestions, and notification settings."

**VISUAL:** Permissions section

> "The permissions section lets you control who can vote and who can submit suggestions. Guest voting is enabled by default, which I recommend keeping."

**VISUAL:** Save changes

> "Make any changes you want, then click Save Changes."

---

### STEP 5: ADD YOUR OWN ITEMS (4:15 - 5:00)

**VISUAL:** Roadmap → All Items → Add New

**NARRATOR:**
> "Time to add your own roadmap items. Go to Roadmap, then Add New Item."

**ON-SCREEN TEXT:** "Step 5: Add Roadmap Items"

**VISUAL:** New item editor

> "This is the item editor. Give your item a title - this is the feature name customers will see and vote on."

**VISUAL:** Enter title and description

> "Add a description explaining the feature. Be as detailed as you want - this helps customers understand what they're voting for."

**VISUAL:** Right sidebar - status, category

> "On the right, select a status - probably 'Planned' for new items. Choose a category like Feature, Enhancement, or Bug Fix."

**VISUAL:** Click Publish

> "Click Publish, and your item is now live on your roadmap!"

**VISUAL:** View on frontend

> "Let's check the frontend... and there it is, ready for votes."

---

### STEP 6: EMBED ANYWHERE (5:00 - 5:30)

**VISUAL:** Any WordPress page → Add shortcode

**NARRATOR:**
> "Your roadmap page was created automatically, but you can embed the roadmap anywhere using a shortcode."

**ON-SCREEN TEXT:** "Step 6: Embed Anywhere"

**VISUAL:** Type shortcode

> "Just add this shortcode to any page or post: [roadmap product='main']"

**VISUAL:** Preview showing roadmap

> "The roadmap appears wherever you place the shortcode. You can add parameters to customize which items show, which template to use, and more."

**VISUAL:** Show shortcode with parameters

> "For example, add 'status=planned' to only show planned items, or 'template=ideabox' for a different layout."

---

### WRAP UP (5:30 - 5:50)

**VISUAL:** Completed roadmap with real content

**NARRATOR:**
> "And that's it! You now have a fully functional public roadmap where customers can vote on features and submit their own ideas."

**ON-SCREEN TEXT:** "You're All Set!"

**VISUAL:** Links to more resources

> "Check the description for links to our documentation, Pro features overview, and support. If you found this helpful, please like and subscribe for more WordPress tutorials."

**VISUAL:** Logo + website

> "Thanks for watching, and happy roadmapping!"

**ON-SCREEN TEXT:** "wbcomdesigns.com/product-roadmap"

## Production Notes

### Screen Recording Requirements
- Clean WordPress install
- Product Roadmap plugin file ready
- No other plugin conflicts
- Clean theme (Twenty Twenty-Four or similar)
- Browser with no distracting extensions

### Recording Tips
- Use 1920x1080 or higher resolution
- Zoom in on important elements
- Slow mouse movements for clarity
- Highlight clicks with cursor effects
- Pause briefly after each action

### Chapters (for YouTube)
```
0:00 Introduction
0:20 Installing the Plugin
1:00 Running the Setup Wizard
2:30 Viewing Your Roadmap
3:15 Customizing Settings
4:15 Adding Your Own Items
5:00 Embedding Anywhere
5:30 Wrap Up
```

### Common Questions to Address
- "Where is the roadmap page?" → Created by wizard
- "Can I use without wizard?" → Yes, manually create everything
- "How do I delete demo content?" → Edit items, move to trash
- "Does it work with my theme?" → Yes, any theme
