# Product Roadmap - Screenshot Requirements

## Overview

This document lists all screenshots needed for marketing materials. Use this as a checklist when capturing screenshots for slides, videos, website, and social media.

---

## Screenshot Specifications

### General Requirements
- **Resolution:** 1920x1080 minimum (2560x1440 preferred)
- **Format:** PNG (for quality) or WebP (for web)
- **Browser:** Chrome (latest) in incognito mode
- **Theme:** Use a clean, modern WordPress theme (e.g., Flavor theme or SeedProd)
- **Demo Data:** Use the plugin's demo import feature
- **User State:** Clear any personal data, use generic names/emails

### Naming Convention
```
roadmap-[section]-[feature]-[version].png

Examples:
roadmap-frontend-board-view-1.3.0.png
roadmap-admin-settings-general-1.3.0.png
roadmap-pro-analytics-dashboard-1.3.0.png
```

## Screenshot Capture Checklist

### Pre-Capture Setup
- [ ] Fresh WordPress install with latest WP version
- [ ] Product Roadmap 1.3.0 installed and activated
- [ ] Roadmap Pro Addon 1.3.0 installed and activated (for Pro shots)
- [ ] Clean theme installed (no conflicting styles)
- [ ] Demo data imported via setup wizard
- [ ] Browser zoom at 100%
- [ ] Browser extensions disabled
- [ ] Incognito/private mode (no personal data)

### Capture Process
- [ ] Close unnecessary browser tabs
- [ ] Hide browser bookmarks bar
- [ ] Full-screen browser if capturing whole page
- [ ] Use screenshot tool with cursor hidden
- [ ] Save in PNG format initially
- [ ] Name files according to convention

### Post-Capture
- [ ] Review all screenshots for quality
- [ ] Crop/resize as needed
- [ ] Add annotations if required (arrows, highlights)
- [ ] Optimize file sizes for web
- [ ] Organize in folders by category
- [ ] Create WebP versions for website use

## Annotation Guidelines

When adding annotations to screenshots:

### Colors
- **Primary highlight:** #2563EB (blue)
- **Success/positive:** #16A34A (green)
- **Warning/attention:** #EA580C (orange)
- **Arrows/pointers:** #DC2626 (red)

### Styles
- **Arrows:** 3px stroke, rounded ends
- **Boxes:** 2px stroke, rounded corners (8px radius)
- **Callouts:** Rounded rectangle with tail
- **Numbers:** Circle with number inside (for step sequences)

### Font
- **Labels:** Inter or system font, 14-16px, bold
- **Descriptions:** Inter or system font, 12-14px, regular
