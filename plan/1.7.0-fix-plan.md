# Product Roadmap 1.7.0 — Consolidated Fix Plan (Free + Pro)

**Branch:** `1.7.0` (both plugins) · **Source audit:** `audit/FUNCTIONAL_AUDIT_2026-07-11.md`, `audit/AUDIT_SUMMARY.md`
**Principle:** fix by ROOT CAUSE, not by symptom. The 43 raw findings collapse into **12 workstreams** below — no duplicate patches. Every workstream lists the raw issues it closes and its verification (browser checklist item).

**Guiding goal (why this release matters):** a Pro buyer today does NOT get the three things Pro is sold on — analytics, advanced filtering, real multi-product management. W1–W3 fix exactly that. Ship those or stop promoting Pro on them.

## Workstream detail

### W1 · Free↔Pro hook contract  [P0, free+pro]
**Root cause:** Free renamed/omitted hooks; Pro still listens on old names → Pro features silently no-op.
**Approach:** define ONE canonical name per event in a shared constant list. Where Free already fires (`roadmap_vote_submitted`, `roadmap_status_changed`, `roadmap_comment_submitted`), point Pro's listeners at those. Where Free fires nothing (`roadmap_item_viewed`), ADD the `do_action` in Free (view = on single-item render / REST item fetch). Fire `roadmap_api_query_args`, `roadmap_api_settings`, `roadmap_shortcode_atts`, `roadmap_settings_fields/_sections`, `roadmap_after_main_content` in Free at the right points so Pro extensions attach.
**Files:** free `class-roadmap-api.php`, `class-roadmap-notifications.php`, `class-roadmap-voting.php`, `class-roadmap-shortcode.php`, `class-roadmap-settings.php`, `class-roadmap-template.php`; pro `class-roadmap-pro-analytics.php`, `-filters.php`, `-settings.php`, `-templates.php`.
**Verify:** BT-ANALYTICS, BT-FILTERS, BT-SETTINGS-TAB (see checklist).

### W2 · /analytics/track param mismatch  [P0, pro]
**Approach:** align REST arg names with the JS payload (`event_type`, `data`) OR change JS to send `event`/`item_id`/`metadata` — pick one, update both sides + `register_rest_route` args.
**Files:** pro `class-roadmap-pro-analytics.php`, `assets/js/roadmap-pro.js`.
**Verify:** BT-ANALYTICS (events table gains rows on vote/view).

### W3 · Multi-product model consolidation  [P0, free+pro]
**Approach:** taxonomy `roadmap_product` is canonical. (1) Remove reads of `_roadmap_product_id`; resolve product by taxonomy slug in Pro `/timeline`, `/export`, `/products`. (2) Delete the disabled product-CPT code OR fully re-enable it under a DIFFERENT name — do not keep a dead `register_post_type('roadmap_product')` colliding with the taxonomy. (3) Decide global view: add `product=all`/omit-to-mean-all to `/items` (remove the mandatory-param requirement) or document single-product-by-design.
**Files:** pro `class-roadmap-pro-api.php`, `-products.php`, `-timeline.php`, `-export.php`; free `class-roadmap-cpt.php`, `class-roadmap-api.php`.
**Verify:** BT-MULTIPRODUCT, BT-TIMELINE, BT-EXPORT.

### W4 · Version + release hygiene  [P0, LAST]
Pro `readme.txt` Stable tag → 1.7.0; both plugin headers + readme → 1.7.0; add GPL license header to Pro main file; changelog entries in WooCommerce action-prefix style (New/Improve/Fix/Security/Dev/Compat, no em-dash, no emoji). **Files:** both main php + readme.txt. **Verify:** BT-VERSION.

### W5 · Frontend board pagination  [P1, free]
Expose load-more/pager in Vue board (REST already returns `total`, accepts `page`/`per_page`); show "X of Y"; clamp `per_page` server max (e.g. 100); emit `X-WP-Total`/`X-WP-TotalPages`. **Files:** free `vue-app/` board components + `class-roadmap-api.php`. **Verify:** BT-PAGINATION.

### W6 · Votes index migration  [P1, free]
Add `KEY created_at (created_at)` + `KEY item_created (item_id, created_at)` to `wp_roadmap_votes` via versioned dbDelta (bump a schema-version option, run on upgrade). **Files:** free `product-roadmap.php` / migration. **Verify:** BT-SCALE-QUERIES (Query Monitor: no full scan).

### W7 · Scale query rewrites  [P1, pro, after W6]
CSV export: paged batches + batched comment counts (no `-1`, no per-post `wp_count_comments`). Status chart: one grouped `COUNT(*)...GROUP BY`. Progress: one `AVG()` SQL. Timeline/export REST: paginate. Analytics: transient cache + write-invalidation. `get_product_item_count`: grouped count, not per-product loop. Merge: set-based vote migration. **Files:** pro `-export.php`, `-analytics.php`, `-api.php`, `-merge.php`. **Verify:** BT-SCALE-QUERIES, BT-EXPORT.

### W8 · Security + input validation  [P1, free+pro]
Add real `permission_callback` to Pro REST (guest-suggest public+rate-limited; approve/reject/merge = `current_user_can`). Add nonce+capability to free vote + nopriv path and the 3× nonce-without-cap in Pro. Replace direct `$_POST`→`update_option` with Settings API + `sanitize_callback`. **Files:** free `class-roadmap-api.php`; pro `-api.php`, `-settings.php`, `-guest-suggestions.php`. **Verify:** BT-SECURITY.

### W9 · uninstall.php + i18n  [P2, free+pro]
`uninstall.php` in both (drop custom table(s), `delete_option` all keys, remove terms if owned). `load_plugin_textdomain()` in both main files on `init`/`plugins_loaded`. **Files:** both. **Verify:** BT-UNINSTALL, BT-I18N.

### W10 · A11y + UX standards  [P2, free+pro]
`<label for>`/`aria-label` on inputs; `:focus-visible` rings wherever `outline:none`; replace `alert()`/`confirm()` with in-UI notice/modal. **Files:** both templates/vue/css/js. **Verify:** BT-A11Y.

### W11 · Enum consolidation  [P2, pro]
One canonical list each for `period` and custom-field `type`; admin/REST/service all read it. **Files:** pro `-analytics.php`, `-api.php`, `-custom-fields.php`, `-settings.php`. **Verify:** BT-FILTERS (period options match API).

### W12 · phpcbf cleanup  [P2, after code churn]
`phpcbf` both; triage residual manual items. **Files:** both. **Verify:** CI green (PHPCS) — no browser item.

### W13 · Product-gap backlog  [P3, post-1.7.0 — owner decision]
Not in 1.7.0 unless chosen. Listed in de-dup map.
