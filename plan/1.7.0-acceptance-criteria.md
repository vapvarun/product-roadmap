# Product Roadmap 1.7.0 — Acceptance Criteria (Site-Owner Expectation Gate)

This is the **pass/fail contract** the automated pipeline checks before release. It turns "does the plugin do what we tell buyers it does" into measurable gates. Each row is `PROMISE → HOW WE MEASURE → THRESHOLD`. Release is blocked until every **MUST** row is green. Mirrors `readme.txt` claims + `audit/FUNCTIONAL_AUDIT_2026-07-11.md`.

Machine-readable companion: `plan/1.7.0-acceptance.json` (pipeline reads this; keys = IDs below).

## Release decision
- **GO** only when every **MUST** is green on seed dataset AND clean install.
- Any MUST red → pipeline stops at that gate, reports the workstream that owns it.
- SHOULD reds are logged as known-issues in the release notes, not blockers.
