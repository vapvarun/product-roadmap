## Verdict

**Up to the mark for 1.7.0:** the core loop a buyer judges first — submit → vote
(incl. guest) → comment → statuses/columns → **status change emails the people who
voted** → changelog with per-product release notes → analytics — all work, and the
whole frontend is now theme-accent, semantic-status, dark-mode-correct and
responsive across all five layouts. That is a credible, shippable product.

### Fix NOW before tagging 1.7.0 (small, real)
1. **Email unsubscribe** — notification + digest emails have NO unsubscribe link/token (confirmed). Add one (CAN-SPAM / expectation).
2. **Basic spam defense** on votes + logged-in suggestions — at least a honeypot + reuse the Pro per-IP throttle pattern (cheap, high-value against abuse). Today only Pro *guest* suggestions are throttled.

(Originally listed the analytics admin page as a bug — that was a false alarm from an
`includes/`-only grep. The page is registered in `roadmap-pro-addon.php` and works.)

### Strong post-1.7.0 roadmap (the real differentiators, not blockers)
- **Private / access-controlled boards** (per-role or gated) — top B2B ask.
- **GDPR** export/erase via `wp_privacy_*` hooks — compliance blocker for EU sites.
- **"Notify me when this ships"** email capture on vote — the Canny/Nolt hook.
- **Server-side search** + **global all-products view** — scale + UX.
- **Bulk status actions** in admin; **Action Scheduler** for digests/webhooks.
- **Native Slack** notify; **JSON/print export**; **changelog subscribe + feed**.
- **White-label** toggle; **per-status colour** config in admin.

### Verified this pass
- ✅ **Custom CSS** field exists (Pro Settings → Templates, sanitised).
- ✅ **Analytics admin page** registered + working (`roadmap-pro-addon.php`).
- ❌ **Unsubscribe** link — not present in notification/digest emails.
- ❌ **White-label / branding** toggle — none found.
- ❌ **Per-status colour** admin UI — status colours are CSS-semantic only (changelog *types* are configurable; roadmap *statuses* are not).
- ⚠️ **Changelog RSS** — only the CPT archive feed, not a curated changelog feed.
