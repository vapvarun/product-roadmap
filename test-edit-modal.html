Roadmap Edit Modal Test

Test Steps:

  1. Navigate to a single roadmap item page
  2. Check if you can see the "Edit this item" button
  3. Open browser console (F12)
  4. Click the edit button
  5. Check console for debug messages

Debug Commands (run in console):

// Check if RoadmapApp is loaded
console.log('RoadmapApp:', window.RoadmapApp);

// Check if debug helper is loaded
console.log('Debug Helper:', window.RoadmapEditDebug);

// Get the container
var container = document.getElementById('roadmap-edit-app');
console.log('Container:', container);

// Check container data
console.log('Config:', container?.dataset?.config);

// Try to get Vue instance
console.log('Vue Instance:', container?.__vue_app__);

// Manual test - try to open modal for item ID 1
if (window.RoadmapEditDebug) {
    window.RoadmapEditDebug.tryOpenModal(container, 1);
}

Expected Console Output:

  • [Roadmap Edit] Initializing edit handler
  • [Roadmap Edit] Edit button found
  • [Roadmap Edit] Edit button clicked
  • [Roadmap Edit] Item ID: [number]
  • [Roadmap Edit] Container found
  • [Roadmap Edit] RoadmapApp available
  • [Roadmap Edit] Vue app mounted successfully
  • [Roadmap Edit] Calling openSingleItemModal

Common Issues:

  • No edit button: Check user permissions
  • RoadmapApp not loaded: Vue assets not enqueued properly
  • Container missing: Template issue
  • Method not found: Vue app not properly exposed

File Locations:

  • Template: /templates/single-roadmap-item.php
  • Edit Handler: /assets/js/roadmap-single-edit.js
  • Vue App: /vue-app/src/App.vue
  • Modal Component: /vue-app/src/components/ItemModal.vue
