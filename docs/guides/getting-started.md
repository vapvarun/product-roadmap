# Getting Started with Product Roadmap

**Time to complete: 5 minutes**

This guide will help you install and set up your first roadmap.

## What You'll Learn

- How to install the plugin
- Running the setup wizard
- Creating your first roadmap item
- Displaying the roadmap on your site

## Step 1: Install the Plugin

### Automatic Installation (Recommended)

1. Log into WordPress admin
2. Go to **Plugins > Add New**
3. Search for "Product Roadmap"
4. Click **Install Now**
5. Click **Activate**

### Manual Installation

1. Download the plugin zip file
2. Go to **Plugins > Add New > Upload Plugin**
3. Select the zip file
4. Click **Install Now** then **Activate**

## Step 2: Run the Setup Wizard

After activation, you'll automatically see the setup wizard.

### Welcome Screen

Click **Let's Get Started!**

### Configure Your Product

**Product Name**: Enter your product name
- Example: "My Awesome App"
- This shows in page titles

**Item Labels**: Customize terminology
- Singular: "Feature" (or Task, Story, Item)
- Plural: "Features" (or Tasks, Stories, Items)

Click **Continue**

### Enable Features

Choose what users can do:

- ☑ **Enable Voting** - Let users vote on items
- ☑ **Enable Comments** - Let users discuss items
- ☑ **Enable Suggestions** - Let users submit ideas

Click **Continue**

### Import Demo Content (Optional)

**Should you import demo items?**

✅ **Yes** - If you want to see examples
- Imports 11 sample items
- Shows how the roadmap looks
- Can delete later

❌ **No** - If you're ready to add real items
- Start with a blank roadmap
- Add your own items

Make your choice and click **Continue**

### Finish Setup

The wizard creates:
- A roadmap page with shortcode
- Default statuses and categories
- Initial settings

Click **View Roadmap** to see your new page!

## Step 3: Create Your First Item

Now add a real roadmap item.

1. Click **Roadmap > Add New Item**

2. **Fill in details:**
   - **Title**: "Add dark mode support"
   - **Description**: Explain what this feature does
   - **Status**: Select "Planned"
   - **Category**: Select "Feature"

3. **Set priority:**
   - Choose: Low, Medium, High, or Critical
   - Example: "High"

4. **Optional fields:**
   - Target Date: When you expect to finish
   - Progress: 0% (just starting)

5. Click **Publish**

Done! Your first item is live.

## Step 4: View Your Roadmap

The setup wizard created a page for you.

**To view it:**
1. Go to **Pages** in WordPress
2. Find "{Your Product} Roadmap" page
3. Click **View**

You'll see your roadmap with the item you created!

## What's on the Roadmap?

Your roadmap shows:
- **Status Columns**: Planned, In Progress, Completed, etc.
- **Item Cards**: Each with title, description, votes
- **Vote Button**: Users can click to vote
- **Comment Count**: Shows discussion activity

## Next Steps

Now that your roadmap is set up:

1. **Create More Items** - Add your product plans
2. **Manage Statuses** - Customize your workflow
3. **Configure Settings** - Fine-tune options
4. **Share Your Roadmap** - Let users see it

## Quick Tips

**Keep it simple**: Start with 3-5 items
**Update regularly**: Move items between statuses weekly
**Engage users**: Respond to votes and comments
**Be transparent**: Explain delays and changes
