## What is Product Roadmap?

Product Roadmap is a WordPress plugin that lets you:

- **Share your product plans** with customers and stakeholders
- **Collect feature requests** and feedback from users
- **Let users vote** on what matters most to them
- **Track progress** from idea to completion
- **Publish changelogs** to announce releases

Whether you're building a SaaS product, WordPress plugin, mobile app, or any digital product, Product Roadmap helps you communicate openly with your audience.

## Feature Overview

### Free Features

| Feature | Description |
|---------|-------------|
| Roadmap Items | Create unlimited items with status, priority, and progress tracking |
| Status Workflow | Customizable statuses (Under Review, Planned, In Progress, Complete) |
| User Voting | Let logged-in or guest users vote on items |
| Comments | Enable discussions on roadmap items |
| Shortcode Display | Embed roadmaps anywhere with `[roadmap]` |
| Changelog | Document releases with version numbers and dates |
| Templates | Choose from Kanban board, list view, or idea box layouts |
| Single Item Pages | Dedicated pages for each roadmap item |
| REST API | Integrate with external tools and apps |

### Pro Features

| Feature | Description |
|---------|-------------|
| Analytics Dashboard | Track votes, views, and engagement metrics |
| Multi-Product Support | Manage separate roadmaps for different products |
| Timeline View | Interactive Gantt chart for visual planning |
| Drag & Drop | Move items between statuses visually |
| CSV Import/Export | Bulk manage items with spreadsheet workflows |
| Advanced Filtering | Filter by priority, date, assignee, progress |
| Dependencies | Link related items together |
| Gutenberg Block | Visual roadmap builder without shortcodes |
