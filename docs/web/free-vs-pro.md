## Who Should Use Free?

The free version is perfect if you:

- Have a **single product** to manage
- Need basic **voting and feedback** collection
- Want a simple **public roadmap** display
- Are **starting out** and testing the concept
- Have a **small team** with basic needs

### Free Version Includes

**Content Management**
- Unlimited roadmap items
- Customizable status workflow
- Priority levels (Low, Medium, High, Critical)
- Progress tracking (0-100%)
- Categories and tags for organization

**User Engagement**
- Voting for logged-in users or guests
- Comments on roadmap items
- Feature suggestion form
- Vote count display

**Display Options**
- Minimal layout (clean, single-column roadmap)
- Theme-aware styling that adopts your accent color
- Dark mode driven by your theme's own light/dark toggle
- Shortcode with filtering options
- Single item pages

*(Board, List, Cards, Timeline, and Idea Box layouts are Pro.)*

**Developer Features**
- REST API for integrations
- Hooks and filters for customization
- Clean, documented code

## Frequently Asked Questions

### Can I start with Free and upgrade later?

Yes. The Pro addon works alongside the free plugin. All your existing items, votes, and settings are preserved when you add Pro.

### Do I need Free if I buy Pro?

Yes. Pro is an addon that requires the free plugin. Install both:
1. Install Product Roadmap (free)
2. Install Product Roadmap Pro (addon)
3. Activate your Pro license

### What happens if my Pro license expires?

- Pro features stop working
- Your data remains intact
- Free features continue working
- Renew anytime to restore Pro

### Is there a trial?

No formal trial, but:
- Free version lets you test core functionality
- You can evaluate if the concept works for you
- Pro is available if you need advanced features

### Can I get a refund?

Check the refund policy at time of purchase. Most licensing issues can be resolved with support.
